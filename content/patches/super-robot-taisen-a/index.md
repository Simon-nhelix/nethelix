ZIP에는 **설치 없이 사용하는 오프라인 패처**(`한글패치.html`), 적용 안내(`읽어주세요.txt`), xdelta 패치 파일과 글꼴 라이선스가 들어 있습니다. 게임 ROM은 포함하지 않습니다.

## 가장 쉬운 적용 방법

1. ZIP 파일의 압축을 풉니다.
2. **`한글패치.html`**을 브라우저로 엽니다. PC의 Chrome·Edge를 권장합니다.
3. 일본판 원본 ROM을 고르면 맞는 원본인지 바로 알려 줍니다.
4. **패치 적용하고 저장**을 누릅니다. 결과 파일 검증까지 자동으로 합니다.
5. 저장된 파일을 GBA 에뮬레이터에서 엽니다.

추가 패치 프로그램 설치나 인터넷 연결이 필요 없습니다. 파일은 사용자의 컴퓨터 안에서 처리되며, 원본 파일은 변경되지 않습니다.

HTML이 글자로 열리면 파일의 **연결 프로그램**에서 브라우저를 선택해 주세요. 메신저나 압축 프로그램의 미리보기 대신, 압축을 푼 실제 파일을 열어야 합니다.

기존 패치 도구를 쓰려면 ZIP 안의 `srta-ko-rc2.xdelta`를 xdelta3·Delta Patcher 같은 도구로 원본에 적용하세요. 결과는 같습니다. 모바일 브라우저의 파일 처리와 저장은 기기별로 확인하지 않았습니다.

## 확인 범위와 알아 둘 점

추출한 시나리오 원고 23,073개와 전투 원문 10,614개에 대응하는 번역을 ROM에 반영했습니다. 시작 메뉴와 주요 메뉴·그래픽 한글화도 포함합니다.

- 결과는 16MB 롬입니다.
- 테스트판입니다. 모든 주인공과 분기를 끝까지 플레이해 확인하지는 않았습니다.
- 긴 무기 이름 19개는 무기 목록 한 줄에 들어가게 줄였습니다(예: 파이널다이나믹ＳＰ, 스토너선샤인).
- RC1 의 일반 세이브는 그대로 이어집니다. 에뮬레이터 상태 저장 호환은 보증하지 않으니 세이브는 따로 백업해 두세요.

## 문제를 발견했다면

아래 댓글에 **화수/장면, 선택한 주인공과 분기, 화면에 나온 문구, 증상**을 남겨 주세요. 재현 가능한 한글화 문제를 중심으로 후속 수정하겠습니다. 처음부터 모든 대사를 검사하며 플레이하실 필요는 없습니다.
